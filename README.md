# Shanmugasundaram C — multi-page portfolio

This is a static, multi-page portfolio designed for deployment on Vercel. The homepage is intended to fit within a single desktop viewport, with navigation to dedicated routes.

## Files
- `index.html` — single-screen home
- `summary/index.html` — professional summary
- `work/index.html` — selected delivery examples
- `experience/index.html` — experience timeline
- `skills/index.html` — skills and credentials
- `ask/index.html` — static hiring-manager Q&A (not a live chatbot)
- `contact/index.html` — contact links
- `assets/styles.css` — responsive styling
- `assets/script.js` — light/dark theme toggle
- `assets/Shanmugasundaram_C_Profile.pdf` — concise profile snapshot, not a full detailed CV

## Deploy
Upload the folder contents to the root of the GitHub repository connected to Vercel. Keep the route folders and `assets` folder at repository root. Commit to `main`; Vercel should deploy automatically. No build command is needed for this static HTML site.

## Before sharing
1. Verify the contact email and decide whether to use a personal professional email rather than a work email.
2. Validate all metrics and dates.
3. Verify the current status of every credential.
4. Replace the profile snapshot PDF with your full, current CV if you want the button to deliver a complete resume.
5. Keep all client and employer-confidential details out of public case studies.
